# AuuRemote

AuuRemote 是 Auu 系列的独立远程桌面项目，采用 Tauri 2、Rust、React、TypeScript 和 Vite。当前原型使用 IronRDP 在应用内显示单个远程桌面。

## 在 Windows 上运行

需要稳定版 Rust、MSVC C++ Build Tools、WebView2，以及 Node.js 20.19（20.x）或 22.12 及以上。

```powershell
npm ci
npm run desktop:dev
```

填写 RDP 主机名或 IP、端口、用户名和密码。域账号可写成 `DOMAIN\user`。应用验证系统信任链和服务器名称。对于自签名证书，先从服务器控制台或其他可信渠道核对 SHA-256 指纹，再到「证书验证」里填写。

「保存连接」会在本机保存名称、地址、端口、用户名和已核对的指纹。左侧可按名称、地址或用户名搜索。密码仅用于本次连接。断线后会保留原连接参数，重新输入密码即可手动重连。

连接后点击画布即可输入。画布缩放时，鼠标位置会换算到远端原始像素。`Ctrl+Alt+Esc` 将键盘焦点移回工具栏。「发送」可把文字直接输入远端当前焦点控件，适合中文等字符。「保存截图」把当前会话的原始像素保存为 PNG。

## 用记事本验收

1. 连接授权的 Windows 测试机，检查画布显示已登录的 Windows 桌面。
2. 在画布内打开开始菜单，搜索并打开记事本。点击编辑区，键入或发送一段唯一的测试文字。
3. 在画布内按 `Ctrl+S`，将内容另存为远端桌面上的新文件。选择当前不存在的文件名。
4. 关闭文件，再从远端文件管理器打开它，核对文件名和文字。点击 AuuRemote 的「保存截图」，检查 PNG 显示重新打开后的文件。

协议回环测试覆盖加密连接、首帧、鼠标和键盘、PNG 与原始帧的一致性、断线后旧会话失效，以及下次连接使用新会话编号。配置测试覆盖保存和编辑、并发写入、损坏配置保护及密码排除。

```powershell
$env:AWS_LC_SYS_PREBUILT_NASM = '1' # Windows x64 上的回环测试依赖
cargo test --release --manifest-path src-tauri/Cargo.toml
npm run desktop:build
```

## 会话与帧

Rust 独占 RDP 连接、解码器和输入队列。React 画布和 PNG 截图读取同一份远端帧，鼠标和键盘事件发给同一会话 ID。断线后旧 ID 立即失效。当前原型支持 TCP、经证书验证的 TLS 和 CredSSP；服务器重新协商桌面时会结束当前会话，重新连接后可继续。原型暂未提供剪贴板、音频、动态分辨率协商或自动重连。
