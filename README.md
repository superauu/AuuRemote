# AuuRemote

AuuRemote 是 Auu 系列的独立远程桌面项目，采用 Tauri 2、Rust、React、TypeScript、Vite 和 Tailwind CSS 4，通过 IronRDP 在应用内显示远程桌面。界面参考 mRemoteNG 布局（连接列表 + 会话标签页 + 配置面板 + 状态栏），视觉体系与 auugit 一致。

## 在 Windows 上运行

需要稳定版 Rust、MSVC C++ Build Tools、WebView2，以及 Node.js 20.19（20.x）或 22.12 及以上。

```powershell
npm ci
npm run desktop:dev
```

## 功能

- **连接管理**：左侧列表保存常用连接（名称、地址、端口、用户名、指纹），支持按名称、地址或用户名搜索。域账号可写成 `DOMAIN\user`。
- **多标签会话**：每个会话在独立标签页中打开，可同时连接多台主机；后台标签降低轮询频率。右键标签页可全屏（F11 退出）、切换自适应（Smart Size）、保存截图、重命名、复制、重连或断开。
- **剪贴板同步**：连接建立后与远端自动双向同步（Windows 标准行为）——本地复制后远端直接粘贴，远端复制后本地应用直接粘贴。支持文本、图片（CF_DIB 原样透传）和**文件**（远端复制的文件自动下载到本地暂存目录并放入剪贴板，可直接粘贴进资源管理器；本地复制的文件远端可直接粘贴）。单文件与单次复制上限 2 GB，每次最多 64 个文件（暂不支持文件夹递归）。
- **主密码密码库**：勾选「记住密码」时，密码用主密码派生密钥（Argon2id + AES-256-GCM）加密保存到本地 `secrets.json`；主密码不设置则不保存密码。解锁状态仅在内存中，退出即锁。
- **证书验证**：应用验证系统信任链和服务器名称。自签名证书先从可信渠道核对 SHA-256 指纹，再到「证书验证」里填写；指纹不匹配时会直接给出服务端指纹供复制比对。
- **双主题与双语**：深色 / 浅色 / 跟随系统三种主题（默认深色），中文 / English 界面切换（默认跟随系统语言）。
- **会话操作**：画布内直接键鼠输入（缩放时坐标换算到远端原始像素），「发送」把文字输入远端当前焦点控件（适合中文），远端 Win+R、保存 PNG 截图，`Ctrl+Alt+Esc` 将焦点移回工具栏。「自适应窗口」会话在窗口尺寸变化时实时更新远端分辨率，全屏时铺满整个屏幕。断线后标签内可一键重连（密码库已解锁时自动带出密码）。

## 用记事本验收

1. 连接授权的 Windows 测试机，检查画布显示已登录的 Windows 桌面。
2. 在画布内打开开始菜单，搜索并打开记事本。点击编辑区，键入或发送一段唯一的测试文字。
3. 在画布内按 `Ctrl+S`，将内容另存为远端桌面上的新文件。选择当前不存在的文件名。
4. 关闭文件，再从远端文件管理器打开它，核对文件名和文字。点击「保存截图」，检查 PNG 显示重新打开后的文件。

## 测试

协议回环测试覆盖加密连接、首帧、鼠标和键盘、PNG 与原始帧的一致性、多会话编号与断线失效，以及 CLIPRDR 剪贴板通道的双向同步（文本与文件各一条：服务端宣布 → 客户端拉取、客户端宣布 → 服务端拉取，含 FileContents 流式传输）。配置测试覆盖保存和编辑、并发写入、损坏配置保护及密码排除。密码库测试覆盖主密码校验、错误密码拒绝、改密重加密与损坏文件保护。

```powershell
$env:AWS_LC_SYS_PREBUILT_NASM = '1' # Windows x64 上的回环测试依赖
cargo test --release --manifest-path src-tauri/Cargo.toml
npm run desktop:build
```

## 架构与边界

Rust 独占 RDP 连接、解码器、输入队列、密码库加密和剪贴板通道；React 通过 Tauri 命令读取同一份远端帧、发送输入。所有命令错误以 `{code, detail}` 结构返回，由前端字典本地化。剪贴板为自研 Win32 后端（`rdp/clipboard/`）：独立消息泵线程监听本地变化，worker 以 eager 模式双向同步，远端文件经 FileContents 流式下载到应用缓存目录后以 CF_HDROP 放入本地剪贴板；`ironrdp-cliprdr` 负责 FDW 编解码、锁管理与远端文件名安全过滤。断线后旧会话 ID 立即失效；已出画面的会话掉线时 worker 自动重试（1 秒间隔、最多 3 次，帧版本号跨重连保持递增），期间标签显示"正在重新连接"，连接失败的首次尝试不重试。当前支持 TCP、经证书验证的 TLS 和 CredSSP；"自适应"会话在窗口/画布尺寸变化时通过 Display Control 通道推送新分辨率，并完成服务端触发的 Deactivation-Reactivation 序列（Windows 10+/Server 2016+，不支持该通道的服务器保持原分辨率）。暂未提供剪贴板文件夹递归、音频和连接树文件夹层级。
